API Endpoints Reference

These are the "addresses" the system uses to communicate. You don't need to memorize these, but it's good to know they exist!

Endpoint Purpose Who Can Use
/api/auth/* Login, logout, sign up, sessions Everyone
/api/artworks Get all artworks (public view) Everyone
/api/artworks/admin/* Manage artworks (create, edit, delete) Admin Only
/api/content/* Website content (hero, about, etc.) View: All, Edit: Admin
/api/crm/* Client management, orders, emails Admin Only
/api/agent/* AI chat assistant Everyone

Security Features

Your gallery is protected by multiple layers of security:

🔒
Encrypted Sessions
Your login is protected with secure, encrypted cookies that expire automatically.
🛡️
Rate Limiting
Protection against too many requests, preventing abuse and attacks.
✅
Input Validation
All data is checked and cleaned before being saved to prevent injection attacks.
🔐
Role-Based Access
Only admins can access sensitive areas like price management and CRM.
