[Container: Node.js + Express]
RESTful API providing artwork data, authentication, content management, and file upload capabilities. Protected routes require JWT authentication. Handles featured artwork limit enforcement (max 6).

[Container: SQLite]
Stores artwork metadata, user accounts, site content, and featured status. Tables: artworks, users, site_content.

[Container: Filesystem]
Stores uploaded artwork images in /uploads/artworks/ and legacy images in root directory served via /images/ route.

Level 3: Component Diagram (REST API)

API Routes

Auth Routes
[Component: Express Router]
POST /api/auth/login - Admin login
GET /api/auth/verify - Token validation
Artwork Routes
[Component: Express Router]
GET /api/artworks - List all/featured
POST /api/artworks - Create with upload
PUT /api/artworks/:id - Update
DELETE /api/artworks/:id - Delete
PATCH /api/artworks/:id/featured - Toggle
Content Routes
[Component: Express Router]
GET /api/content/:section - Get content
PUT /api/content/:section - Update content

Middleware & Data

Auth Middleware
[Component: Express Middleware]
JWT verification for protected routes. Validates Bearer tokens and extracts user data.
File Upload Handler
[Component: Multer Middleware]
Handles multipart/form-data uploads. Validates file types (images only), generates unique filenames, saves to /uploads/artworks/.
Database Models
[Component: SQLite Queries]
Schema initialization, seed data, and query methods for artworks, users, and site_content tables.
Static File Server
[Component: Express Static]
/images/* → Root directory (legacy)
/uploads/* → Uploads directory
/ → Public directory

Key Business Logic

Featured Artwork Limit: Maximum 6 artworks can be featured at once. The PATCH /featured endpoint enforces this by checking the count before allowing new items to be featured.

Image Management: When an artwork is deleted, both the database record and the physical image file are removed to prevent orphaned files.

Public vs Admin APIs: Public endpoints exclude prices and only show available artworks. Admin endpoints require JWT authentication and return full data.

Component Elements
Component: Individual code modules within containers (routes, middleware, handlers)
Database: Data access layer components
